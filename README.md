# Đấu Trí X – O

Trò chơi cờ X–O kết hợp trả lời câu hỏi cho 2 đội, chạy trên trình duyệt.

- Hai đội chạy đua (ngẫu nhiên) để chọn đội trả lời trước.
- Mỗi câu trả lời đúng được đánh 1 ô X hoặc O; trả lời sai thì mất lượt.
- Mỗi câu có thời gian suy nghĩ riêng.
- Đội nào có 3 ô thẳng hàng (dọc, ngang, chéo) là thắng.

## Sửa câu hỏi
Mở file `questions.js` và sửa theo mẫu có sẵn trong file.
